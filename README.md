# Uni revision

Revision site for COM106 Introduction to Databases and COM161 Problem Solving for Computing (weeks 1 to 5): notes, spaced-repetition flashcards, multiple choice, fill-the-blanks, exercises, mini tests and reminders.

- `index.html` is the whole site in one file. It works offline, and progress is saved in your browser.
- `uni-revision-calendar.ics` holds the key deadlines and study reminders. Open it to add them to your calendar.
- `source/` is what the site is built from. Edit the `content-*.js` files, then run `python3 source/build.py` and copy `source/dist/index.html` to the repo root.
